# Scriblyx

로컬 우선 마크다운 노트 앱. 노트는 그냥 `.md` 파일이고, AI 에이전트가 직접 읽고 씁니다.

---

## 왜 만드나

노트 앱은 많습니다. 그런데 대부분 내가 쓴 글을 자기네 서버의 자기네 형식으로 가져갑니다. 서비스가 문을 닫으면 글도 같이 묶이고, 다른 도구로 옮기려면 내보내기를 거쳐야 합니다.

Scriblyx는 반대 방향으로 갑니다.

**노트 하나 = `.md` 파일 하나.**
앱을 지워도 글은 폴더에 그대로 남습니다. 데이터베이스도, 독자 포맷도 없습니다.

**앱이 없어도 읽힙니다.**
탐색기로 열어도, VS Code로 열어도, 10년 뒤에 열어도 그냥 텍스트입니다.

**AI 에이전트가 1급 사용자입니다.**
Claude Code 같은 도구가 노트 폴더를 직접 읽고, 쓰고, 검색합니다. 내보내기도 API 토큰도 플러그인도 필요 없습니다. 파일이 거기 있으니까요.

## 현재 상태

개발 초기입니다. 아래가 지금 동작하는 전부입니다.

| 기능 | 상태 |
|---|---|
| 노트 만들기 · 편집 · 자동 저장 | 동작 |
| 이름 바꾸기 (파일명에 반영) | 동작 |
| 삭제 | 동작 |
| 로컬 `.md` 파일로 저장 | 동작 |
| 외부 변경 감지 — 다른 도구가 파일을 고치면 즉시 반영 | 동작 |
| 평문 편집 | 동작 |
| 서식 있는 편집 (제목 · 굵게 · 목록 · 표) | 미구현 |
| MCP 서버 | 미구현 |
| 기기 간 동기화 | 미구현 |
| 검색 | 미구현 |
| 음성 녹음 → 텍스트 변환 | 미구현 |

플랫폼은 **Windows · macOS · iOS** 를 대상으로 합니다. 현재 빌드와 동작을 확인한 것은 Windows뿐입니다.

## 노트가 저장되는 곳

처음 실행하면 아래 폴더를 만들고 바로 시작합니다. 아무것도 묻지 않습니다.

```
Windows   C:\Users\<사용자>\Documents\Scriblyx\
macOS     ~/Documents/Scriblyx/

Scriblyx/
├── personal/   내 기기끼리만 동기화할 노트
└── shared/     다른 사람과 공유할 노트
```

폴더가 동기화와 공유의 단위입니다. 개인 노트는 `personal/` 밖으로 나가지 않습니다.

## 구조

`Flutter` 단일 코드베이스로 세 플랫폼을 대상으로 합니다. 아키텍처는 Flutter 공식 권장안인 **MVVM + Repository** 를 따릅니다.

```
View  ──>  ViewModel  ──>  Repository  ──>  Service  ──>  파일시스템
          (화면 상태)     (진실의 원천)     (외부 I/O)
```

```
app/lib/
├── main.dart                  진입점
├── config/dependencies.dart   구체 구현을 연결하는 유일한 지점
│
├── domain/models/             순수 Dart 모델. 다른 계층을 모른다
│
├── data/
│   ├── services/              파일 입출력, 변경 감시, 설정
│   └── repositories/          노트의 진실의 원천
│
├── ui/
│   ├── core/editor/           에디터 계약과 구현
│   ├── note_list/             목록 ViewModel + View
│   ├── note_edit/             편집 ViewModel + View
│   └── home/                  레이아웃과 화면 연결
│
└── utils/command.dart         비동기 동작의 실행 상태
```

교체 가능성이 높은 부분(에디터, 저장소)은 인터페이스 뒤에 둡니다. 에디터 구현을 바꿀 때 수정하는 곳은 `ui/core/editor/` 와 `config/dependencies.dart` 뿐입니다.

## 빌드하기

### 준비물

- [Flutter SDK](https://docs.flutter.dev/get-started/install) 3.47 이상
- **Windows**: Visual Studio 2022 이상, C++ 데스크톱 개발 도구. 그리고 개발자 모드를 켜야 합니다 (`설정 → 개인 정보 및 보안 → 개발자용`)
- **macOS / iOS**: Xcode

### 실행

```bash
cd app
flutter pub get
flutter run -d windows     # 또는 -d macos
```

### 검사

```bash
cd app
flutter analyze
flutter test
```

## 앞으로

순서대로 진행합니다.

1. **에디터** — 서식 있는 편집. `.md` 원문을 손상 없이 왕복하는 것이 조건입니다.
2. **MCP 서버** — AI 에이전트가 노트를 읽고 쓰고 검색하는 경로.
3. **동기화** — 기기 간 `.md` 파일 동기화. 충돌은 기준 버전 비교 후 3-way 병합으로 처리하고, 해결되지 않으면 사본을 남깁니다.
4. **검색** — 로컬 전문 검색.
5. **구조** — 폴더, 태그, 노트 간 링크.
6. **음성** — 녹음 후 로컬에서 텍스트로 변환.
